# RC-PostFlow 過去の検証履歴

本書は、RC-PostFlowの過去バージョンで実施した検証について、公開に不要な環境固有情報や機密情報を除いて記録したものです。

## 対象と注意事項

- 対象バージョンは`v0.2.0-pre1`です。
- 以下は過去バージョンに対する確認実績であり、現行`v0.3.0`の検証結果ではありません。
- 環境固有のホスト名、Token、投稿内容、アカウント情報は記載していません。

## 2026年7月5日

- Linux環境へデプロイしました。
- systemdサービスとして起動しました。
- Threadsへの実投稿成功を確認しました。
- 24時間耐久試験を開始しました。

この記録は試験開始を示すものであり、「24時間耐久試験を完了した」ことを示すものではありません。

## 2026年7月6日

- 予約投稿の成功を確認しました。
- サービスが継続稼働していたことを確認しました。
- エラーなしと記録されています。

## v0.3.0との区別

上記は`v0.2.0-pre1`に対する過去の手動確認履歴です。v0.3.0の自動テスト結果や、v0.3.0を使用した最新のThreads実投稿確認を示すものではありません。v0.3.0でThreadsへ実投稿する場合は、導入環境ごとに有効なAccess Tokenを使用して確認してください。
